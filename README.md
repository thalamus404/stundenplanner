# Stundenplanner

Stell deinen Stundenplan schneller, einfacher und übersichtlicher zusammen.

*Create your timetable faster, simpler and cleaner.*

**Die Seite:** [stundenplanner.de](https://stundenplanner.de)

**Stand:** im Aufbau. Ziel ist eine erste Fassung im Netz zur Einführungswoche im Oktober 2026.
Die Termine kommen einmal am Tag aus den öffentlichen Seiten von MOSES der TU Berlin.

Ein privates Projekt, **kein offizielles Angebot einer Hochschule**. Verbindlich sind immer die
Angaben und Anmeldungen in den Systemen deiner Hochschule.

**Lizenz:** noch keine. Der Code ist öffentlich lesbar, eine Lizenz folgt.
